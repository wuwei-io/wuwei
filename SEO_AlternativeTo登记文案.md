**Full description**（详情框，直接整段粘）
```
Wuwei is a free, open-source (MIT), local-first AI agent desktop app. Tell it what you want in one sentence and it reads and writes files, makes precise code edits, runs commands, and searches the web to finish the task end to end — with a permission prompt before anything risky.

Unlike editor plugins or chat boxes, Wuwei is a standalone agent with a fully self-built, auditable harness. Your project and code stay on your own machine, with no hidden telemetry and no region tagging.

Key points:
- Genuinely free — works out of the box, no subscription, no credit card
- Local-first — your code never leaves your machine
- Bring any model — Claude, any OpenAI-compatible endpoint, local models (vLLM / Ollama), or Chinese LLMs (DeepSeek, GLM, Kimi), switch in one click
- Bring your own key (BYOK) or use Wuwei's hosted credits with zero config
- Permission prompts before writing files or running commands
- Works on Windows, macOS, and Linux

A practical open-source alternative to Cursor, GitHub Copilot, Claude Code, Windsurf, Cline and other AI coding tools — for people who want a standalone, local, model-agnostic agent they can actually own.
```
