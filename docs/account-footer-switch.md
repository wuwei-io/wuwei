## 钱包

新增主进程固定 allowlist action `wallet`，仍从主进程带 token 请求，不把凭证交给渲染层。
服务端 `/api/billing/wallet` 只认登录 token 的账号，忽略调用者指定的账号。
复用现有 `billing_account` 懒结算，然后从私有只读 `account_wallet_snapshot_v1` 读取一致快照；没有新增结算/发币/扣费写入器。
按真实剩余批次和到期时间分组；永久余额=可用余额−有期限批次。Infinity 批次不被当作会员到期。
当前计划只认生效中的已付订阅，排除未来续期和已取消订阅；兼容会员单独标识，不靠签到额猜计划。
余额与批次不平、RPC 失败或跨账号响应时明确提示不可用；不虚构零余额、过期规则或新赠币。
中英文新文案已提供；其他现有语言包的新文案使用英文回退，正式发行前可继续本地化。

## 每日签到与到期倒计时（2026-11-02，本地 dev）

无期限余额排在有期限余额上方；有期限余额按真实批次展示逐秒倒计时及到期日期。倒计时以钱包服务器 asOf 校准，浮层收起即停止计时，到期或领取资格重置时主动刷新，不能显示负数或把过期值当作新余额。
每日签到信息取私有钱包快照 daily，单列基础数量、今日是否已签到、下次资格重置倒计时与领取后有效期。免费及 billing_v2 计划当前是 10 币，签到后 24 小时到期；领取按 UTC 自然日（北京时间 08:00）重置。旧会员按实际 signin_daily 和连续第七日加成，原领取规则保持。缺少新字段时显示暂不可用，不硬编码猜测每日数量。
配套后台仅扩展 account_wallet_snapshot_v1 只读返回，migration 为 20261102_account_wallet_daily.sql；不改签到或财务写入函数，不重启服务。客户端未发行，只更新独立分支及本地 dev。


## 快捷签到与已领取赠币失效（2026-11-02，覆盖此前领取倒计时展示）

用户明确：倒计时用于已到账赠币的失效，删除「下次领取资格重置」倒计时。未签到时提供「立即签到，领取 N 币」，复用原签到 IPC；原菜单签到保留。快捷签到在浮层内完成，不再弹出原居中签到弹窗，成功后从真实钱包重读新批次并显示失效倒计时，不从按钮点击时间推算到期。
失败可重试、请求中防重复；账号切换隔离迟到结果。到期时原钱包读取器调用 billing_account 懒结算，独立服务 wuwei-billing-grants.timer 每分钟运行 billing_sweep；未使用余额按批次自动失效，无期限余额保留。后端金融规则未修改。
使用线上实际签到、批次触发器、分配与到期函数在独立临时数据库验证：领取 10，消费 4，到期只失效 6；重复签到和重复到期不重复记账，测试数据库已删除。UI/生产账户检查只读，不代用户执行真实签到。
