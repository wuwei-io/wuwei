# 视频创作实现（2026-10-25）

已将确认的浅色无为视频设计接入独立创作视图。侧栏提供入口；切换比例、时长、分辨率、数量与声音只更新视频组件，不切换聊天模型或重建整个应用。参考图支持首帧，以及当前模型允许的尾帧。

结果包含批量作品、真实任务状态、播放器、原文件下载、提示词与参数复用、收藏和详情。生成后输入栏收起；悬停、点击或键盘聚焦展开，可以固定展开。展开不改变结果区域尺寸。收藏只填实爱心，不增加高亮背景。

## 模块

- `src/videogen/contracts.ts`：客户端视频协议。
- `desktop/main/video-studio.ts`：带账号鉴权的 API 桥接、账号隔离的草稿/待确认请求、SHA256 校验、本地视频缓存和私有媒体协议。
- `desktop/renderer/src/components/VideoStudio.tsx`、`video-studio.css`：输入、模型与参数菜单、结果和详情。
- `desktop/renderer/src/App.tsx`：独立视频入口，保留原聊天/图片工作区。

服务端位于网站仓库 `src/lib/video/`、`gateway-standalone/video-server.ts` 和 `supabase/migrations/20261025_video_studio.sql`。线上 `/api/videos/` 由独立视频服务处理。

## 任务与费用

报价包含预估费用和明确的最高预占额度；批量先原子预占。提交编号在发起请求前持久化，重试使用原编号。服务端保存上游任务和提交回执，重启继续查询，提交结果不确定时不自动重新生成。

视频文件通过格式、元数据和哈希校验后，使用上游任务费用及独立 generation 回执核对，再按预占时的汇率与加价结算。未使用的有效预占额度释放；不会复活已过期的币或向新会员周期补发旧额度。超出授权时须用户确认，只结算原任务。
