# wuwei 手机端 · 落地方案（v1 定稿）

> 状态：已定稿。当前执行策略 = **先做「能对话的内测包」验证真机体验，再决定是否全量做**。
> 决策人：董事长；统筹：小笨(CEO)；技术：小码。

## 一、已定决策

| 项 | 决策 |
|---|---|
| 技术路线 | React Native + Expo（一套代码 iOS+安卓），定位**轻量版** |
| 手机端定位 | 随身对话 / 看进度 / 审批；重度本地工具（文件/命令/浏览器/MCP）仍留桌面端 |
| 云端服务 | 复用现有阿里云（systemd + nginx，与 wuwei-site 一套） |
| 账号 | 复用官网 HTTP 契约（token / /api/me / /api/refresh），不碰 Supabase SDK；两端同一账号 |
| 会话表 | 用**现有 Supabase 项目**（与账号/pay_config 一套） |
| iOS 内购 | MVP **不做**充值入口，只显余额、引导去电脑/官网充值，App 内无支付按钮（规避审核红线） |
| 会话互通 | 目标要两端互通；**内测阶段先不做**（互通 = 桌面端额外 14 人天，见 C 线） |
| 官网回调页 | /auth/mobile 计入本项目，由小码做 |

## 二、当前阶段：内测包（最小范围）

只做到"能对话"，供董事长真机体验：
- Expo 工程脚手架、导航、主题、EAS 出包
- 账号打通：deep-link 登录（官网 /auth/mobile 回调）、token 存取/续期
- 云端薄 SSE 对话服务：复用 src/agent + provider，无状态转发，流式回复
- 手机对话界面：消息流、markdown 渲染、流式打字
- 会话独立存云端（现有 Supabase），**暂不与桌面互通**

**内测包工期估算**：官网页 2 + 云端 A1~A3 约 10 + 手机 B1~B3 约 15 ≈ **27 人天**（可并行压缩）。

## 六、最大风险与应对

1. 云端服务是新组件、要扛并发/流式 → MVP 做无状态转发（每请求从库拉历史重建 Agent），不常驻内存态。
2. iOS 内购合规 → MVP 不放支付入口，只引导去电脑/官网充。
3. 手机端功能预期错位 → 明确"随身指挥+审批+看进度"，重活提示转电脑端。

## 七、手机端内测包 · 页面 & 功能清单（设计输入 / 给小美）

> 范围：只覆盖"能对话"内测包。不含看进度/审批/充值（后续版本）。
> 定位：轻量版——随身对话，重活留桌面端。安卓优先。账号 = 官网账号（deep-link 登录），与桌面端同一身份。

### P1. 启动/加载页（Splash）
- 展示：App logo、主色背景、加载态。
- 逻辑：检查本地 token 是否有效 → 有则进会话列表；无/过期则进登录页。
- 设计输入：logo 用法、主色、亮/暗色是否都要。

### P2. 登录页（Login）
- 展示：品牌 slogan、"用无为账号登录"主按钮、底部隐私政策/用户协议链接（上架合规）。
- 交互：点登录 → 系统浏览器打开官网 `/auth/mobile` → 授权后 deep-link 回跳 App → 进会话列表。
- 状态：登录中 loading、失败提示（网络/取消）。
- 说明：唯一未登录页，第一印象页，极简。**无账号密码输入框**（走官网回跳）。

### P3. 会话列表页（Sessions）— 首页
- 展示：会话列表（标题 + 最后一条摘要 + 时间）、顶部账号入口、醒目"＋新对话"按钮。
- 数据：云端 `wuwei_sessions`（当前用户，按 updated_at 倒序）。
- 交互：点进对话页；＋新对话 → 空白对话页；左滑/长按 → 重命名/删除；下拉刷新；空态引导。
- 设计输入：列表项样式、空态、新对话按钮位置（建议右下悬浮）。

### P4. 对话页（Chat）— 核心页 ⭐
- 展示：消息流（用户右/助手左）、助手消息支持 markdown、流式打字、"正在思考/联网搜索"状态提示、顶部会话标题（可改名）+返回、底部输入框+发送（发送中可"停止生成"）。
- 交互：发消息、停止生成、长按复制、滚动到底、键盘弹起不挡输入框。
- 数据：历史从云端会话拉；新消息经 A 云端服务 SSE 流式返回。
- 特殊：用户让干"本地重活"时，助手友好拒绝"请在电脑端完成"——需专门的**提示气泡样式**（区别普通消息）。
- 设计输入：花最多时间的页——消息气泡、markdown 排版、流式态、工具运行态、输入区。

### P5. 我的/设置页（Me）
- 展示：账号（昵称/邮箱/头像）、**余额只读展示** + "如需充值请前往电脑端或官网"（**无支付按钮**，iOS 合规）、退出登录、版本号、隐私/协议链接。
- 数据：账号来自 `/api/me`，余额来自账号接口（只读）。
- 交互：退出登录（清 token 回登录页）。
- 设计输入：余额卡片 + 引导话术呈现（清楚但不像禁用按钮）。

### 全局设计输入
- 导航：底部 Tab 2 个——【对话】(P3/P4) + 【我的】(P5)；或极简对话栈 + 右上角进"我的"。请小美给建议。
- 主题：延续 wuwei 桌面端视觉（主色/字体调性）。
- 暗色：内测可先只做亮色，有余力给暗色（可选）。
- 平台：安卓优先，Material 手感；iOS 随后适配。
- 状态覆盖：每页都要 加载态/空态/错误态（尤其对话页、列表页）。
- **不在本次范围**（别设计）：看进度页、审批页、充值/支付页、团队编排、复杂设置。
