# 一人公司：可配置的近期上下文与本地摘要（2026-10-10）

## 行为

设置 → 一人公司 → 对话上下文：

- 保留最近消息数：默认 10，允许 2–100 条。
- 自动摘要旧消息：默认开启。生成不超过 1600 字符的本地摘录，记录最初请求与靠近保留窗口的旧消息片段；不是额外调用模型做语义总结。关闭后不附旧消息摘要。
- 已打开的员工私聊、员工间私聊、公司群聊在下次模型请求时读取配置。普通未绑定员工的聊天保持原行为。

限制作用于发送给模型的历史，不删除原始消息。近期的旧正文与工具返回还有 12000 字符预算、每文本块 2400 字符上限；当前用户输入保持原文。工具调用/结果保持配对，长工具链保留当前任务，因此个别请求可比设置条数略多。系统提示词、工具定义、当前图片/输入及工具参数仍计入实际 token，不能把消息数当成总 token 上限。

## 实现与存储

- `src/team/history-window.ts`：请求历史投影；本地摘录、正文截短、旧图片占位及工具配对。
- `desktop/main/team/history.ts`：摘要缓存在用户数据目录 `team/context-summaries/`。相同摘录复用缓存；配置每次请求读取。缓存损坏或写入失败时仍按窗口发送，不退回全部历史。
- `src/agent/loop.ts`：发送前应用投影；公司对话跳过原有付费自动摘要路径。完整消息仍由原会话机制持久化。
- `desktop/main/index.ts`：同时覆盖绑定员工的普通会话与 room/DM；后绑定员工的现有 Agent 也更新策略。
- `CompanyHistorySettings.tsx`：条数输入、摘要开关、保存错误提示。

本地摘录会省略历史细节，不等同完整长期记忆。此前已经手动删除或被旧机制裁剪的内容不会被自动恢复。
