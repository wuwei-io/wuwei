# Wuwei 1.7.50

- 模型按免费、高性价比、顶级、生图和自有接入分组，标注图片能力；模型选择窗口尺寸保持稳定。
- 未登录默认使用免费自动挑选；首次登录默认使用高性价比推荐模型，并按账号记住主动选择。点击免费分类默认选中自动挑选，仍可手选其他免费模型。
- 需要登录的模型点击后直接打开登录窗口。免费额度用尽时，按剩余余额引导高性价比模型或充值；付费聊天和生图余额不足时直接打开付款页。
- 顶级模型切换前展示价格和消耗说明，支持改用推荐模型；切换后提示可关闭，10 秒后自动消失。
- 修复授权后隐式切到顶级模型、过期账号/目录响应覆盖新状态，以及上游限流被误判为余额不足的问题。
- 完善网关重试、图片输入能力和上下文容量配置，保留手动执行模式与会员可用额度。
