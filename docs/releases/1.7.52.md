# Wuwei 1.7.52

- 修复登录续期：网络异常时保留凭证，登录真正失效时提示重新登录。
- 加密支付按当前订单号自动检测到账，成功后刷新账户并展示到账结果和订单号。
- 新增“我已付款，重新查询”，支持查询失败自动重试、等待延迟及订单失效提示；关闭窗口或切换网络时停止旧订单查询。
- 普通工具默认自动允许，减少 bash、PowerShell 等操作的重复权限弹窗；仍可在设置中切换为手动，智能继续保持独立开关。
