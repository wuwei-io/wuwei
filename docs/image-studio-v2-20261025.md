# 图片创作 V2 浅色界面

已落地用户确认的浅色稿，并合入 mini-day-trial 当前测试版。品牌使用月白、冷灰、靛青和朱赭主操作；厂商图标直接使用原生素材。

## 交互

- 模型菜单按四个品牌分组，支持跨品牌搜索、特点、当前目录的起步费用、真实可用规格和会员皇冠。
- 每次生成按批次展示独立原图，支持四列 / 两列、描述展开、搜索、最近一天 / 七天和收藏筛选。
- 大图预览支持缩略图与左右键、完整描述和参数、真实尺寸、真实费用、实际耗时和本地年月日时分秒；下载原始 PNG，单张或本组下载均不重压缩。
- 复用原始描述与确切 SKU，准备单张重试时重置为一张，取得当前报价后由用户点击生成。
- 原订单状态不明时只查原订单并尝试在原授权内结算，不创建新付费订单；恢复结果写入原工具结果，避免重复作品。
- 图片、参数与批次信息保存在会话；收藏按当前账户 / 会话存放。参数选择继续走局部 IPC，无全局 ready / account 刷新。

## 目录与真实能力

已通过 OpenRouter 独立 Images API 接通设计稿中的 13 / 14 款型号，共 639 个真实规格，保留原有 109 个 SKU。OpenAI、Google、Seedream、xAI 共用现有服务端 OpenRouter 账户和余额；每个型号已逐一真实生成并取得独立费用回执。

尚缺旧版 Seedream 4.0：OpenRouter 当前未提供，菜单保留禁用说明并提示使用已接通的 4.5；fal.ai 有精确 4.0 接口，但当前没有该平台凭证，没有虚报为可用。Seedream 4.5 的公开目录虽列 1K，实际调用会被渠道最小像素限制拒绝，因此只开放 2K / 4K。

Seedream 5.0 Pro、GPT Image 2.5 Sunburst、Nano Banana Pro 标记会员皇冠，仅有效 Pro / Plus / Max 可选；Mini 不包含这些专享型号。菜单、报价、创建接口与数据库原子预占均检查资格，已授权订单不受随后会员到期影响。

新增 OpenAI 2.5 的超清 / 极致档位；token 估价采用官方 2.5 计算规则，独立于 GPT Image 2。所有型号最终均按独立核对的 OpenRouter 实费结算，不把费用总额与 token 费用重复相加。

当前仍为文字生图；参考图入口明确显示尚未开放。设计素材没有作为用户作品植入产品。

## 耗时与服务端

成功任务按模型 / 规格统计近七日 P50–P90，至少五条成功样本才显示，不足五条时使用明确注明“单次试测”的技术验证耗时；没有该证据才显示“耗时待实测”。新增任务在第一次供应商响应时记录 duration_ms，后续对账不覆盖该值；历史空值不回填伪造耗时。

本次统一接口更新五个编译模块，保留原凭证工厂、原资产存储和原订单快照。新增价格版本只替换当前可选目录，历史版本保留。供应商明确在生成前拒绝的请求可凭原始错误证据释放其预占；超时、429、5xx、原订单状态不明仍只核对原订单，不能自动重发生成。

视频完成目录、规格、单价与备选平台调研：OpenRouter 当前有 30 款，可沿用同一账户；本次未启用视频生成界面，也未执行付费视频生成。

## 验证

前端类型检查、桌面构建和 18 个语言包检查通过。54 项客户端回归、47 项扩展设置 / 画廊 UI 检查通过，包括 17 种比例在 600px 高窗口内无滚动条、五档画质和参数局部更新。

后台 72 项测试通过。639 个规格的原子预占与重复释放、会员资格、历史价格不可变和 13 份真实费用回执结算在隔离数据库验证，完成后立即删除数据库。供应商真实调用是独立技术探测，没有对真实用户余额建立验收订单。

另实测 Seedream 4.5 的 2K 宽图、Flare 的 4K 长图和极致画质成功；返回的真实图像经过完整解码验证。当前测试版的 31 个会话、草稿、选中规格、语言与主题保留。部署与调研证据见工作区 outputs/media-provider-integration-20261025。
